# Развёртывание на Timeweb Cloud

## Целевая схема

- GitHub хранит только код и публичные изображения.
- Timeweb Cloud App Platform запускает `node server.mjs` из репозитория и автоматически обновляет приложение после push.
- Timeweb Cloud DBaaS PostgreSQL хранит контент, заявки, согласия и события в регионе Москва или Санкт-Петербург.
- Секреты задаются только в переменных окружения Timeweb и никогда не коммитятся.

GitHub Pages можно оставить временной демонстрацией. Его формы не должны подключаться к PostgreSQL напрямую: пароль базы неминуемо окажется в публичном JavaScript.

## Порядок запуска

1. Создайте PostgreSQL 16+ в Timeweb Cloud, выбрав российский регион и включив резервное копирование.
2. Создайте приложение из GitHub-репозитория. Команда запуска: `npm start`; версия Node.js — 22 или новее.
3. По возможности подключите приложение и БД к одной приватной сети. В `DATABASE_URL` используйте приватный адрес БД.
4. Добавьте переменные из `.env.example`. Для production обязательно:

   - `NODE_ENV=production`
   - `HOST=0.0.0.0`
   - `TRUST_PROXY=true`
   - `DATABASE_URL=...`
   - `PII_ENCRYPTION_KEY=...`
   - `EVIDENCE_HASH_SECRET=...`
   - все `ADMIN_*`, `SESSION_SECRET`, `OTP_SECRET` и `SMTP_*`

5. Один раз выполните `npm run db:migrate` с теми же переменными окружения. Не запускайте несколько миграций параллельно.
6. Откройте `/api/health`: ожидается `{"status":"ok","database":"ok"}`.
7. Войдите в `/admin`. Если база пустая, текущий встроенный каталог загрузится в неё автоматически.
8. Подключите домен и HTTPS, затем проверьте заявку, смену статуса, добавление работы и повторный вход после перезапуска приложения.
9. Настройте ежедневный запуск `npm run db:cleanup` и контролируйте резервные копии БД.

## Резервное восстановление

Периодически скачивайте JSON-копию каталога в админке. Персональные данные заявок в неё намеренно не включены. Копия каталога дополняет, но не заменяет снимки PostgreSQL; восстановление проверяйте на отдельной тестовой БД, не на рабочей.

## Перед открытием для клиентов

Заполните юридические реквизиты, снимите `noindex` с `privacy.html`, `consent.html` и `terms.html`, подайте уведомление в Роскомнадзор и проведите финальную проверку по `legal/LEGAL-CHECKLIST-RU-2026.md`.

Актуальные инструкции провайдера: [App Platform](https://timeweb.cloud/docs/apps), [как работает деплой приложений](https://timeweb.cloud/docs/apps/how-it-works), [DBaaS](https://timeweb.cloud/docs/dbaas), [создание базы данных](https://timeweb.cloud/docs/dbaas/dbaas-create), [PostgreSQL](https://timeweb.cloud/docs/dbaas/postgresql).
